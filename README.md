# 🧩 Konundrum - Challenge & Riddle Platform

Een interactieve website waar gebruikers riddles/challenges moeten oplossen met progress tracking.

## Features
- User Login/Registration
- Challenge System
- Progress Tracking per User
- Leaderboard

## Getting Started
1. Clone deze repository
2. Open `index.html` in je browser
3. Start met inloggen!

- HTML5
- CSS3
- JavaScript
